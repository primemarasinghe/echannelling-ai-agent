# How to Book an Appointment

1. Search for a consultant by name, by medical specialty, or by hospital.
2. Select a session on the date you want. Each session shows the number of
   appointment slots still available.
3. Provide the patient name and a contact mobile number.
4. Confirm the booking summary, which shows the doctor, hospital, date, time and
   total fee.
5. Complete payment. A booking reference and an appointment number are issued once
   payment succeeds.

An appointment number is your position in the doctor's queue for that session. It is
not a fixed clock time. Patients are asked to arrive at least 30 minutes before the
session start time.
